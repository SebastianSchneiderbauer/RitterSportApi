Ritter Sport Photo API

Get one of 77 photos. IDs run from 0 to 76. Each endpoint returns a JPEG image and an X-Photo-Id response header.

  • GET /api/photos/:id — view photo 0
  • GET /api/random — view a random photo
  • GET /api/today — view the Ritter Sport of the day

An unknown ID returns HTTP 404 with a JSON error.

Ritter Sport of the day

Changes every day at 00:00 UTC. Next reset: the next 00:00 UTC.
